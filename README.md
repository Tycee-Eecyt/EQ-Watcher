# EQ Watcher

EQ Watcher is a local EverQuest log trigger watcher for Linux and Windows. It
opens its dashboard in your browser and listens only on `127.0.0.1`.

## Install

Download the newest files from the repository's **Releases** page.

### Linux

Extract `EQ-Watcher-linux-x86_64.tar.gz`, open the extracted folder, and run:

```sh
./install-linux.sh
```

The per-user installer writes to `~/.local/share/eq-watcher`, adds an
application-menu entry, and preserves existing settings during upgrades. The
browser dashboard works with Python 3 alone. Native overlays additionally need
GTK 3 Python bindings; on Debian/Ubuntu install `python3-gi python3-cairo
gir1.2-gtk-3.0`.

### Windows

Run `EQ-Watcher-Setup-windows-x64.exe`. It is a per-user installer and does not
require administrator privileges. The dashboard, log watching, timers,
inventory, and triggers work on Windows; GTK-based transparent desktop overlays
are currently Linux-only.

Choose the EverQuest `Logs` directory in the dashboard if it is not detected.

Features:
- Watches a configurable EverQuest `Logs` directory
- Follows the newest `eqlog_*.txt` file by default
- Supports regex triggers
- Shows alert cards and countdown timers
- Compares `/outputfile spellbook` exports with P99 Wiki class spell lists,
  grouped into owned and missing spells by level
- Combines the newest `/outputfile inventory` export for every character, with
  item search, character filtering, and EQCM-compatible common Raid Kit filtering
- Shows the current Green-server Scout Charisa timer from PigParse
- Shows current EverQuest and local real-world times beneath the dance character
- Accepts a local Ring 8 roll time in common Eastern-time formats and adds it
  to the Spell Timers overlay during the final 30 minutes
- Uses browser speech and beep alerts
- Saves settings in `data/config.json`
- Offers manual or opt-in automatic checks for public GitHub release metadata

## Updates

Open **Setup → System** to check manually or enable automatic update checks.
The app only reads this repository's public latest-release metadata. When a new
version is available, **Download update** opens the matching Linux archive or
Windows installer. Updates are never downloaded or installed without a click.

Release builds are generated by GitHub Actions whenever a `v*` tag is pushed.

## Spellbook checklist

Run `/outputfile spellbook` on a character, open the **Spellbook** tab, and
select **Scan**. EQ Watcher checks the normal EverQuest directory and the
RAM-backed Wine client directories automatically. The character class is
inferred from the exported spells and the character level is read from the
latest matching `eqlog_*.txt`; both can be overridden in the tab.

The bundled class catalog is generated from the Project 1999 Wiki spell lists
and links every level back to `p99wiki.eqgeeks.org`. Developers can rebuild it
with `python3 update_spell_catalog.py`.

The PigParse integration is read-only. EQ Watcher makes one bodyless HTTPS GET
to the public Green Scout timer endpoint and never sends logs, character names,
zones, settings, timer updates, or other application data to PigParse. It does
not follow redirects and cannot POST, PUT, PATCH, or DELETE there. As with any
web request, PigParse can still observe standard connection metadata such as
the public IP address and request time.

When PigParse's Scout timestamp has passed, EQ Watcher advances it in 10-hour
Scout spawn cycles until the next future time and labels that countdown
`Next guess` so it cannot be mistaken for a tracked estimate.

## Development

Run from source with `python3 linux_gina.py` or `./run-linux-gina.sh`.

```sh
python3 -m py_compile linux_gina.py update_spell_catalog.py
```

The test workflow also checks the embedded browser JavaScript and inventory
helpers. User configuration, logs, generated audio, and backup files are
excluded from Git.
